## 生成说明

## 填写与内容验收

系统运行拓扑、构建装配依赖和调用次序分别在其所属槽位解释，允许必要图表但不新增章节。模块与链路均保持固定字段，共用机制摘要引用真实正文；没有专题也须保留接手判断所需上下文。源码、构建、运行、部署、数据、测试、运维和文档分别判断，未知不当缺失，缺失须有预期材料依据。行动表引用缺口、前提、通过标准及产出，不复制第二份判断。
