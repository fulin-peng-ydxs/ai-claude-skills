# 技能正文默认骨架

本文件是创建或获准整体重构自有技能的正文模板权威入口；使用与裁剪规则由 [SKILL.md](../SKILL.md) 维护。模板中的说明指导填写，不原样复制到交付技能。

重构使用本骨架前后，按 [语义保留审查](../SKILL.md#重构的语义保留审查) 核对原有核心契约的去向、变更依据及关键场景。该检查属于技能编写过程，不照抄到目标技能的业务验证章节。

填写前按 [正文与独立资源的选择](../SKILL.md#正文与独立资源的选择) 确定内容位置；本骨架不要求每个主题另建参考文件。

## 默认模板

以下正文采用默认骨架；YAML 的 `name`、`description` 是必需机器字段，目标环境支持的既有可选字段应按需保留。

填写名称前读取 [命名规范](skill-naming.md)，先选统一一级领域，再填写细分对象与任务能力；目录名与 `name` 使用同一英文标识，中文标题与已配置的 UI 名称保持一致。

```markdown
---
name: skill-name
description: 描述具体能力、触发场景，以及容易误触发时的必要边界。
---

# 技能中文名称

## 职责与边界
说明技能负责哪些工作、不负责哪些工作，以及与相邻技能的分工。
按 [共用声明骨架](~/ai-agent-config/config/force/document-boundaries.md#共用声明骨架) 说明本文件维护哪些规则、相关规则由哪些文件维护；复用本章节，不另设同义章节。

## 输入与前置条件
说明实际需要的信息、优先获取来源，以及信息缺失时可继续或必须等待的条件。

## 执行流程
按任务展开可操作的流程，覆盖关键判断、适用分支及停止条件。
引用专项资源时说明何时读取，不要求所有任务加载全部资源。

## 核心约束
仅写影响本任务决策的专项规则；通用规则引用权威入口。

## 产出边界与交付
明确交付物包含什么、排除哪些易混入的内容。
说明返回方式、何时落盘、保存位置，以及适用的最低内容或固定字段；不自动生成相邻技能负责的产物。
若需要产物模板，声明其结构策略；按实际读取与维护需要内联或引用独立模板，不重复维护两份定义。
生成文档前读取上述共用声明骨架；在产物模板、输出契约或内联结构的实际生成位置填写该类文档的用途、维护内容和关联内容归属，报告承接范围与时点；不能只在本技能中声明或在模板外提醒。
仅保存、逐字保存或局部更新时保留授权基线，范围外缺口在交付说明中报告。

## 验证与完成标准
说明可观察的完成结果、适用的验证方式和证据，以及失败或未验证时的处理。
```

## 裁剪示例

- 简单转换技能：输入可并入执行流程，格式限制并入产出边界与交付；产出边界也可与职责边界合并，仍需明确支持的转换范围、交付范围、失败条件和结果检查。
- 多模式分析技能：共享主题保留在入口，在流程中按输入选择专项参考文件，不将各模式全文复制到入口。
- 局部修订现有技能：只维护受影响内容，不要求将旧标题改名为模板标题。

示例说明组织选择，不规定所有技能的业务步骤、交付物或验证命令。
