# 五维股票质量分析

使用公开、可追溯的数据分析盈利能力、成长性、现金流与财务安全、商业模式与护城河、股东回报与估值。默认中文；跟随用户语言。

## 先选择模式

- **完整分析**：首次分析、重新分析、打分或用户未明确要求增量更新。
- **季报跟踪**：用户要求跟踪或更新，且当前上下文中存在该公司的完整分析基线。没有基线时说明无法可靠比较变化，并执行完整分析；不要假装记得其他会话中的报告。

完整分析读取 [methodology.md](references/methodology.md) 和 [report-templates.md](references/report-templates.md)。季报跟踪读取 [quarterly-tracking.md](references/quarterly-tracking.md) 和报告模板。需要取数、选择来源或处理冲突时读取 [public-data-sources.md](references/public-data-sources.md)。

## 工作流

1. 解析并核对公司全称、ticker、交易所和报告币种。用户只给公司名时，先用交易所、监管披露或公司官网确定唯一 ticker；只有存在真实歧义时才询问。
2. A 股优先运行 `scripts/collect_a_share_data.py` 收集结构化公开数据，再依据数据源规则核对最新官方定期报告。使用临时目录，避免把原始数据写入用户项目：

   ```bash
   task_data_dir="$(mktemp -d)"
   python3 scripts/collect_a_share_data.py --ticker 600519.SH --output "$task_data_dir"
   ```

   脚本失败或 AKShare 不可用时，转为网页取数；不要自动安装依赖。港股、美股及其他市场直接按数据源规则使用交易所、监管文件、公司投资者关系网站和公开行情源。
3. 建立证据账本：每个关键数值记录指标、数值、单位、报告期/价格日期、来源、获取日期、原始值或计算公式。聚合站只负责提效，官方披露是最终事实源。
4. 检查完整性、时效性、口径、单位、复权、累计期与单季度、追溯重述以及同行可比性。先完成数据质量检查，再计算、评分和写结论。
5. 按相应模式输出。硬数据、公司口径、外部观点和分析推断必须明确区分；每项评分必须展示证据与口径。

## 不可违反的约束

- 不得编造、默认为零、线性外推或用行业常识补齐缺失数据。接口失败是“获取失败”，不是“无数据”。
- 搜索摘要只能帮助定位，关键数字必须打开原始页面或报告核实。付费墙后的摘要、无日期转载、自媒体和 AI 摘要不能作为唯一证据。
- 来源冲突时依次采用：监管/交易所披露与经审计报告、公司正式公告、政府或行业组织数据、可复核的公开聚合数据、媒体与研究观点。披露差异和选择理由必须写出。
- 一致预期、市场份额、管理层评价或核心驱动因子证据不足时标记 `N/A`。缺失评分项按区间处理，不得偷偷给 0、1 或 2 分。
- 所谓“当前价”必须附交易日期；只有最新收盘价时写“最新收盘价”，不得写成实时价。
- 建仓区间是基于公开数据和明示假设的情景分析，不得伪装成确定预测或个性化投资建议。关键估值或盈利基准缺失时，不输出价格和仓位数字，只给需要补齐的数据与观察条件。
- 引用紧跟结论。公开网页使用可点击链接；本地结构化数据注明原始提供方、数据集、报告期/日期和获取日期。

## 完成标准

交付前复核：ticker 无误；五年与十年窗口符合规则；单季度计算正确；至少核对最新官方报告；所有表格单位一致；评分可复算；缺失项影响透明；结论没有超出证据；风险、证伪条件和下次跟踪信号可执行。
