# 公网数据源与证据规则

## 来源层级

| 级别 | 来源 | 用途 |
|---|---|---|
| A | 监管机构、证券交易所、法定披露平台、经审计定期报告、公司正式公告 | 财务、治理、融资、分红、分部和风险的最终事实源 |
| B | 政府部门、商品交易所、行业协会、指数公司 | 宏观、行业、价格、产量、市场份额和周期位置 |
| C | 无登录即可访问且能追溯原始提供方的结构化聚合数据 | 批量取数、历史序列、初步同业比较；关键数据需抽查 A/B 级来源 |
| D | 公开券商报告、主流财经媒体、专家访谈 | 一致预期、竞争格局和解释背景；不能覆盖 A/B 级事实 |

分析推断不是来源级别。推断必须列出前提，并使用“推断”“情景”或“可能”标记。

## A 股来源映射

优先入口：巨潮资讯、上海证券交易所、深圳证券交易所、北京证券交易所、证监会、公司投资者关系网站。结构化取数使用 AKShare 暴露的公开接口；AKShare 是采集层，字段最终含义以原始提供方和公司报告为准。

| 需求 | 首选结构化数据 | 核验与回退 |
|---|---|---|
| 公司、交易所、行业、主营 | `stock_profile_cninfo` | 交易所证券列表、最新年报、公司官网 |
| 资产负债表 | `stock_balance_sheet_by_report_em` | 最新年报/季报原表；检查重述列和合并口径 |
| 利润表 | `stock_profit_sheet_by_report_em` | 同上 |
| 现金流量表 | `stock_cash_flow_sheet_by_report_em` | 同上 |
| ROE、ROIC、毛利率、负债率等 | `stock_financial_analysis_indicator_em` | 用三表复算关键评分项，禁止只抄聚合指标 |
| 主营收入、成本、利润、毛利率 | `stock_zygc_em` | 年报“主营业务分行业/产品/地区”表 |
| 日线价格 | `stock_zh_a_hist` | 交易所行情或另一公开行情源；注明复权方式 |
| 历史 PE/PB | `stock_zh_valuation_baidu` 的“近十年”，`stock_value_em` 交叉检查 | 数据不足十年时使用上市以来，并显式降级评分项 12 |
| 当前同行估值、预测 PE | `stock_zh_valuation_comparison_em` | 同行最新报告、公开行情页；核对预测年份是否仍为未来年度 |
| 盈利预测 | `stock_profit_forecast_em` 全市场结果按股票代码筛选 | 至少检查数据日期、预测年度、覆盖机构数；回退近期公开券商报告和公司业绩指引 |
| 分红 | `stock_fhps_detail_em`、`stock_dividend_cninfo` | 利润分配实施公告；分红率用现金分红总额/归母净利润复算 |
| 股本与融资 | `stock_zh_a_gbjg_em`、`stock_share_change_cninfo`、`stock_allotment_cninfo` | 巨潮检索定增、配股、可转债转股、回购和股权激励公告 |
| 管理层与治理 | 定期报告、董监高变更公告 | 证监会处罚、交易所处分/问询、审计意见、内控报告 |
| 核心驱动因子 | 无通用接口 | 政府统计、商品交易所、行业协会、公司与可比公司经营数据 |

公开入口：

- 巨潮资讯：<https://www.cninfo.com.cn/>
- 上海证券交易所：<https://www.sse.com.cn/disclosure/listedinfo/regular/>
- 深圳证券交易所：<https://www.szse.cn/disclosure/listed/notice/>
- 北京证券交易所：<https://www.bse.cn/disclosure/announcement.html>
- 中国证监会：<https://www.csrc.gov.cn/>
- AKShare 股票接口文档：<https://akshare.akfamily.xyz/data/stock/stock.html>

接口变更时先查当前 AKShare 文档和函数签名，不要凭旧接口名反复重试。单个来源连续失败两次就换来源，并在报告中注明降级。

## 其他市场

- 港股：港交所披露易和公司公告为 A 级；公司财报、经济通或公开行情门户用于结构化补充。
- 美股：SEC EDGAR/XBRL 和公司投资者关系网站为 A 级；交易所、Nasdaq/Yahoo Finance 等公开页面用于行情和一致预期补充。
- 其他市场：优先当地监管机构、交易所与发行人披露。无法核对会计口径、币种或证券标识时停止评分。

## 一致预期的特殊门槛

免费公网数据不能默认等同于付费终端的时点一致预期。只有同时满足下列条件才可用于评分：

1. 明确数据日期，且距分析日不超过 120 天；公司刚披露业绩后优先要求 60 天内更新。
2. FY1–FY3 是最新已披露实际年度之后的三个财政年度，不能把已结束年份当预测。
3. 至少 3 家机构形成的聚合一致预期，或至少 2 份独立、90 天内公开报告方向一致。
4. 报告币种、每股口径和股本稀释口径一致。

不满足时项目 14 为 `N/A`，可以展示公司指引或单家预测，但必须标明“非一致预期”。

## 市场份额与行业地位

优先政府、行业协会或第三方行业统计。公司年报自称“第一/领先”只能标为“公司口径”；至少与一家竞争对手披露或独立统计相互印证，才可作为项目 11 的排名证据。没有可比定义、统计年度、地域和产品边界时为 `N/A`。

## 数据完整性门槛

完整分析至少需要：

- 最近 5 个完整年度的营收、归母净利润、经营现金流、资本开支、权益、负债和利润率；周期判断尽量取得 10 年。
- 最新年报和最新已披露季报，以及同比所需的上年同期数据。
- 最新业务分部、5 年分红记录、10 年股本/股权融资记录。
- 与上市年限相匹配的估值历史；上市满 10 年时，项目 12 需要至少覆盖 9.5 年且有 500 个有效交易日或 120 个有效月末/周度样本。
- 可比公司使用相同会计期、币种或明确换算、相近业务与利润驱动。

缺少前三项中的任一核心数据，不给完整 `/30` 分数或三档价格计划。

## 冲突处理与引用

1. 记录冲突值、各自报告期、发布日期和口径。
2. 优先后来发布的追溯重述、合并报表和法定披露；不能解释时同时展示并停止相关计算。
3. 结构化文件中的数值注明：`[来源：原始提供方/AKShare 数据集，报告期或价格日，获取日]`。
4. 网页事实使用可点击链接，紧跟其支持的句子；同一来源不要承担超出页面内容的结论。
