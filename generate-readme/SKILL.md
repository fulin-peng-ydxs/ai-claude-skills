# Generate README

这个技能只负责一件事：

- 生成或更新项目根目录 `README.md`

## 执行流程

1. 先扫描项目关键文件、目录、配置和现有 README。
2. 提炼项目真实事实：项目用途、技术栈、目录结构、构建方式、运行方式、环境依赖。
3. 生成或更新 `README.md`，优先保证人类读者快速理解和快速上手。
4. 若 README 已存在，优先增量更新，删除过期内容，保留仍然有效的内容。

## README 重点内容

README 应优先覆盖以下必备内容：

1. 项目简介
2. 技术栈
3. 服务架构
3. 环境要求
4. 快速开始
5. 开发命令
6. 配置说明

根据项目复杂度再决定是否补充以下可选内容：

1. 项目结构
2. 部署说明
3. 常见问题
4. 其他说明

## 执行约束

1. README 内容必须输出中文。
2. 仅基于仓库实际文件与实测结果写结论，禁止猜测。
3. 不要照抄 `AGENTS.md` 或 `.claude/CLAUDE.md`，但基础事实必须一致。
4. 不要为了补 README 而改动无关文件。

## 输出要求

输出时至少说明：

1. 扫描了哪些关键文件或目录
2. `README.md` 是新建还是更新
3. 本次主要补充或修正了哪些内容
