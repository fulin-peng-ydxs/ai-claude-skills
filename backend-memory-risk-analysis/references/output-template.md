# 后端内存风险分析产物模板

本文件统一维护报告结构、最低内容、字段和产物边界；分析流程、风险与状态判定、保存路径及基线继承由 [技能入口](../SKILL.md) 维护。首次完整生成时读取，局部更新和仅保存保留授权基线。

生成前读取 [共用声明骨架](~/ai-agent-config/config/force/document-boundaries.md#共用声明骨架)，在下方分析范围中填写报告职责和实际检查时点，基线复用已有字段。

以单条风险为审阅和复核单元；共用运行证据需求集中维护，风险项关联具体判断与处理结果。

采用 [文档结构与输出规范](~/ai-agent-config/config/force/document-output.md) 的默认骨架；分析范围与基线、运行形态、总体判断、逐项风险证据与状态、验证缺口及后续建议必须可辨识。风险编号与字段含义保持稳定，状态值沿用技能入口，不在此另设枚举。报告只维护本次内存风险判断与处理证据，不承载完整架构或运维手册。无风险时保留检查范围与盲区，不生成空风险项。
