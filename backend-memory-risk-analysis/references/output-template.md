# 后端内存风险分析产物模板

本文件维护产物结构与字段；适用条件、最低内容、固定项和完成标准由 [技能入口](../SKILL.md) 维护。按入口的对应分支读取；章节组织按入口声明的结构策略调整，不因迁移模板省略业务字段。

生成前读取 [共用声明骨架](~/ai-agent-config/config/force/document-boundaries.md#共用声明骨架)，在下方分析范围中填写报告职责和实际检查时点，基线复用已有字段。

组织遵循 [面向读者的组织与审阅](~/ai-agent-config/config/force/document-output.md#面向读者的组织与审阅)，以单条风险为审阅和复核单元；共用运行证据需求集中维护，风险项关联具体判断与处理结果。
