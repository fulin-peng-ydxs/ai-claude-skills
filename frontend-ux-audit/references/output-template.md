# 页面体验审核产物模板

本文件维护产物结构与字段；适用条件、最低内容、固定项和完成标准由 [技能入口](../SKILL.md) 维护。首次完整输出读取；仅保存或局部更新保留原成果及证据状态。

生成前读取 [共用声明骨架](~/ai-agent-config/config/force/document-boundaries.md#共用声明骨架)，在下方结论与范围中填写具体职责、权威入口及检查时点。

按 [文档结构与输出规范](~/ai-agent-config/config/force/document-output.md) 使用默认骨架；组织遵循 [面向读者的组织与审阅](~/ai-agent-config/config/force/document-output.md#面向读者的组织与审阅)，以页面任务中的问题为审阅单元。必改、细节优化、风格统一及冗余交互是问题标签，不再要求分别建章；同一问题只写一处，保留全部相关判据和影响。

问题优先展示尚未解决的阻断项与必改项，再展示其它项；同组按 P0 → P3 排序，同级按任务或页面组织。已有编号保持稳定，不因排序重编号。开头结论列出阻断/必改问题编号及影响；已修复项带实际复核状态，未复核不能当作已关闭。无问题时不生成空索引。
