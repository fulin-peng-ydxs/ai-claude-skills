# business-audit.md 模板

本文件维护正式报告的默认骨架及问题字段；模式、授权、范围与证据语义由 [技能入口](../SKILL.md) 维护，核查维度见 [核查清单](audit-dimensions.md)。组织与裁剪遵循 [文档结构与输出规范](~/ai-agent-config/config/force/document-output.md)，以问题为详细说明单元；不因结构整合改变问题类别、证据强度、稳定标识和真实处理状态。

生成前读取 [共用声明骨架](~/ai-agent-config/config/force/document-boundaries.md#共用声明骨架)，在下方结论与范围中填写具体归属；范围与时点复用核查对象和证据字段。

快速核查不写文件，简短表达结论、已确认问题、待业务确认问题、暂无法确认风险及下一步，注明模块为用户确认或推断待确认；不强制展开下列正式骨架。

```markdown
# <业务功能名称>业务核查

## 1. 结论与范围

用途与归属：本报告用于业务闭环核查，维护本次改动的结论、证据、风险及处理状态；完整需求、架构及实施过程沿用{已有权威入口或当前归属}。
核查对象：具体模块、业务功能及拆分依据、目标、代码/版本范围、明确排除项；列出已确认的文件范围或链接到仍有效的范围清单，说明模块确认状态。
结论等级：合理 / 基本合理但有遗漏 / 存在明显闭环缺口 / 风险较高不建议直接上线。
证据强度：confirmed / inferred / missing；注明支持结论的证据时点及限制。
结论摘要：2—4句说明改动放回业务后的结果及主要风险；涉及页面时判断业务入口、状态与操作反馈是否承接闭环。
剩余盲区：未核查或未验证的配置、数据、联调、外部系统、权限及历史兼容范围；不把盲区当作已确认缺陷。

需要处理的重点：引用下方问题标识、优先动作及依赖；没有问题时明确说明未发现问题的范围与限制。

## 2. 核查链路

按业务功能说明本次改动触及的位置及上下游，不重写整个模块架构。
入口/角色 → 核心处理与状态/数据变化 → 对外输出/消费方 → 异常补偿或人工接管。
必要时用图或短表；源码、配置和需求证据在支持的环节就地引用，标明职责及证据强度。
区分已核查、不适用（含依据）和证据不足；前端业务承接包含入口可达性、权限、状态和反馈，不扩成视觉/复用审查。

## 3. 问题与处理

三类问题分别标识；各类优先展示未解决项，再按严重程度和处理优先级排列，已解决项保留时放在未解决项之后。可分组或就地标记，不必分别复制一套模板。开头优先列出影响上线或关键判断的阻塞项，注明其为已确认缺陷、待业务确认或待补证风险；潜在影响评级不作为已确认缺陷统计。

### Q1：问题或风险名称
类别：已确认问题 / 待业务确认问题 / 暂无法确认的风险点。
严重级别：high / medium / low（风险尚未证实时注明为潜在影响评级）。
证据强度：confirmed / inferred / missing。
归属：业务模块、功能及链路位置；涉及页面或上下游时明确受影响入口/消费方。

**证据与触发**
代码/配置/需求的文件、类/方法或规则位置；已知事实与实际验证范围。
触发条件、现有行为与预期差异；推断注明依据，冲突分别列用户规则与代码表现，不强行合并。

**业务影响与处理**
影响的角色、状态、数据及下游结果，建议如何处理及其理由。
待业务确认类：需要决定的规则、选项差异及影响、确认时点。
证据缺失类：缺少的信息、为何不能判断、补证材料/入口和确认条件。

**复验与当前状态**
复验场景、操作/核对方式及可观察的通过条件；外部环境依赖及限制。
当前处理状态及证据：未处理/待确认/待补证/待复验/已解决等按事实填写，不把建议当作已实施或把计划复验当作已通过。
已有结果注明适用版本/环境和证据入口；未执行写明原因及下一步。
```

## 分类与维护

- 已确认问题须有直接支持问题结论的 `confirmed` 证据；待业务确认问题可有 `confirmed` 或 `inferred` 的局部证据，但规则是否成立仍待确认；暂无法确认风险使用 `missing` 并写清缺失信息。无某类问题时简述无该类发现，不制造空条目。
- 问题标识沿用已有值，新项使用未占用标识；排序、分类或状态变化不重编号、不复用旧标识。结论和优先动作是详情的汇总，不维护第二套处理状态。
- 更新已有报告时保留有效范围、业务背景、事实和证据；删除或改写过期结论。新问题加入对应类别或位置，已解决项只有在用户要求保留历史演进时才单列历史；保留的真实处理状态须有证据，不将未核查部分标为已覆盖。
- 复验方式是后续判断建议，不自动授权修代码、部署、联调或其他外部操作。无问题时仍保留结论依据、已核查链路与剩余盲区。
