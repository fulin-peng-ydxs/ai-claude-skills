# 代码审查正式报告模板

本文唯一维护完整正式报告的结构、字段和内容验收；审查流程、问题分类、授权与保存边界由 [技能入口](../SKILL.md) 维护。首次生成或整体重构读取 [文档输出规范](~/ai-agent-config/config/force/document-output.md) 和 [文档边界规范](~/ai-agent-config/config/force/document-boundaries.md)，保存和局部更新保留授权基线。

## 完整模板

````document-template
# 代码审查报告

## 1. 范围与结论

- 用途与归属：{{@本次审查发现及证据归本文，需求、架构及实施结果引用真实权威入口；尚无入口时说明当前归属}}
- 审查范围与基线：{{@仓库、PR或差异范围、版本、实际检查时点及排除范围}}
- 审查结论：{{@按技能入口的结论规则填写，说明依据及限制}}
- 重点与后续：{{@优先处理的发现标识及影响；未发现问题时说明已检查范围，不推定未验证部分通过}}

## 2. 审查发现

### Q{{@序号}}：{{@问题名称}} <!-- repeat -->

- 分类与判断依据：{{@按技能入口的问题分类填写，说明判断及适用项目规范}}
- 位置与证据：{{@实际文件、行或符号、差异版本和支持本条结论的证据；推断及缺项分别标明}}
- 触发与原因：{{@具体输入、条件、现有与预期行为及原因，不把猜测写成已证实}}
- 影响与建议：{{@受影响对象、上下游及最小修复方向，不自动实施或发布评论}}
- 复核与当前状态：{{@能验证风险的场景、通过条件、实际执行结果或未执行原因，建议与已修复分开}}

## 3. 验证与未覆盖

| 检查事项 | 实际执行及结果 | 证据位置 | 未覆盖范围及影响 |
| --- | --- | --- | --- |
| {{@验证目标}} | {{@已执行结果或未执行及原因}} | {{@真实入口或当前缺口}} | {{@限制及对结论的影响}} |

## 4. 后续处理与现场

- 必须修正与依赖：{{@引用发现标识、修正及补证顺序；无则说明依据，不另维护第二份问题正文}}
- 现场恢复与剩余事项：{{@临时切换分支或运行的最终状态、恢复结果及未完成项；未改变现场时说明}}
````

## 填写与内容验收

每条发现能沿证据、触发、影响、建议和复核条件查用，分类沿用技能入口，不以格式、风格偏好冒充正确性缺陷。编号稳定，不因排序重编；结论引用发现，不重复维护状态。没有发现时省略重复条目并在父节说明条目情况、检查依据和限制。

实际检查与静态推断分别记录；未完成审查或必要验证时不暗示批准。修复、评论发布和其他外部写入仍须有对应授权。格式及命令见 [共用模板检查用法](../../skill-authoring-standard/references/template-validation.md)，格式通过不证明代码或运行结果正确。
