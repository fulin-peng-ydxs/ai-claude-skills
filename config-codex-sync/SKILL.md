# Codex 配置同步

## 职责与边界

将 Codex 作为唯一来源，同步用户级技能和协作说明。使用随技能提供的 `scripts/sync_codex_config.py`，不要临时拼接复制命令。

本文维护同步范围、路径适配和目标端验证规则；实际枚举、写入与 CLI 参数由 scripts/sync_codex_config.py 实现，不维护另一套复制逻辑。

## 输入与前置条件

### 默认路径

- Codex：`${CODEX_HOME:-~/.codex}/skills` 与 `${CODEX_HOME:-~/.codex}/AGENTS.md`
- Claude：`${CLAUDE_CONFIG_DIR:-${CLAUDE_HOME:-~/.claude}}/skills` 与同根目录下的 `CLAUDE.md`
- Kimi：`${KIMI_CODE_HOME:-~/.kimi-code}/skills` 与同根目录下的 `AGENTS.md`

命令行路径参数优先于环境变量。不要把展开后的个人绝对路径写入技能或脚本。

### 参数查询

需要完整参数时运行：

```bash
python3 scripts/sync_codex_config.py --help
```

## 执行流程

1. 明确同步目标和范围。
   - 用户指定目标或技能范围时，只处理该范围，不顺带同步其他目标、技能或协作文档。
   - 同时检查待同步技能是否引用自身安装目录、同级技能、配置根目录或目标端可执行文件；这类运行时路径必须先按目标环境适配。

2. 准备同步源。
   - 不需要路径适配且同步完整集合时，直接使用 Codex 根目录。
   - 需要目标端路径适配或只同步部分技能时，使用隔离的临时 Codex 根目录承载所选技能和目标端版本；只修改临时副本，不把 Claude、Kimi 路径反写进 Codex 源技能。
   - 同时同步 Claude 与 Kimi 且适配结果不同时，分别准备目标专用临时源并分目标执行。

3. 选择模式：默认增量同步；用户明确要求删除同步、清理目标残留或镜像对齐时使用 `--delete`。只要求修改本技能时不执行实际删除。删除仅限本次源集合与目标中同名、可同步的技能内部；目标独有技能一律保留。可以使用部分技能临时源，只清理所选同名技能，预览前核对源集合与授权范围一致。

   使用实际同步源先运行预览：

   ```bash
   python3 scripts/sync_codex_config.py --dry-run
   ```

   删除同步预览增加 `--delete --dry-run`；执行时使用相同源、目标及 `--delete`。

4. 检查输出中的源、目标、技能数量、协作文档状态、逐项删除清单和错误；路径适配场景还要核对临时源只包含用户指定范围，适配前后只改变目标相关运行时路径。
5. 用户的请求明确授权同步时，使用与预览完全相同的目标和同步源执行：

   ```bash
   python3 scripts/sync_codex_config.py
   ```

6. 删除同步执行前再次核对源集合及预览清单未变化；变化时重新预览。同步后检查目标文件与实际同步源一致，并验证技能中的运行时路径指向目标安装根目录、被引用文件真实存在、没有遗留会导致目标端误读 Codex 安装目录的路径。
7. 报告每个目标新增、更新、未变化的技能数量、协作文档状态和路径适配结果。提示重新启动或新建 Claude、Kimi 会话以加载新配置。

只同步一个目标时使用 `--target claude` 或 `--target kimi`。非默认安装位置使用 `--codex-root`、`--claude-root`、`--kimi-root`。使用临时源或分目标适配时，预览与执行命令必须显式携带完全相同的 `--target` 和 `--codex-root`，不能在执行阶段退回默认全量源。

## 核心约束

### 目标端路径适配

- 需要适配的是会在目标端实际读取或执行的路径，包括技能安装根目录、同级技能引用、配置根目录和目标端命令位置；Codex、Claude、Kimi 的默认根目录分别以前述“默认路径”为准，非默认位置以本次命令行参数或环境变量为准。
- 只替换路径的环境归属，不改变相对目录、文件名、业务规则和技能语义。能够改成相对引用或目标环境变量时优先使用可移植表达，不写入展开后的个人绝对路径。
- 不得对全部文本做无条件字符串替换。用于比较不同工具、说明同步来源、展示用户输入或记录客观事实的 Codex 路径不属于运行时路径，除非它在目标端确实会被解析或执行。
- 目标专用修改只存在于隔离临时源和目标安装目录；Codex 源始终保留 Codex 自身可执行的路径。临时源必须按目标分别生成，禁止用同一份已适配副本同时覆盖不同目标。
- 预览前检查适配差异，执行后再次扫描目标技能；发现源端专属运行时路径残留、目标路径指向不存在文件或适配范围超出路径归属时，视为同步未完成并立即修正。

### 同步规则

同步已有文档遵循 [文档结构与输出规范](~/ai-agent-config/config/force/document-output.md) 的保留原则：除已定义的目标路径适配外，保留源文档的结构策略、核心内容和固定契约，不在同步过程中重写模板；引用的共享规范须在目标环境可读。

- 只同步 Codex skills 根目录中含 `SKILL.md` 的一级技能目录，以及具有有效 YAML frontmatter 的一级 Markdown 技能文件。
- 禁止同步任何 MCP 相关技能，不区分创建、同步、审计、监控、安全或其他用途。技能目录名、技能文件名或 YAML frontmatter 中出现 `MCP`（不区分大小写）时，预览与执行均排除，并在输出中列出。
- Codex 专属技能不参与同步：`automation-management` 仅供 Codex 自动化使用。按目录/文件标识或 frontmatter 的 `name` 判定，预览与执行均列出排除项；不因其他通用技能提及 Codex 就排除。
- 忽略 skills 仓库元数据、隐藏的系统目录、编辑器目录、缓存和构建依赖。
- 目标中不存在的技能创建；已存在技能中的同名文件按 Codex 内容更新。
- 默认保留目标独有技能及同名技能中的多余文件。显式 `--delete` 时仅删除同名技能内部的多余普通文件和空目录，不删除目标独有技能或同名技能根目录；顶层 README、未识别为技能的目录、隐藏项、仓库元数据、缓存和符号链接均保留。含受保护子项的目录不会整体删除。
- MCP 与 Codex 专属技能同时排除同步和删除，目标端已有副本保持不变。源中存在但未纳入同步集合的同名入口不能视为删除指令；空源拒绝执行。源和目标不可嵌套，目标不可重合，目标 skills 不得为符号链接。
- 删除以当前源集合为准，不以文件时间推断是否过期；不删除项目技能或源端文件。执行前预检全部目标路径冲突，删除失败如实报告已完成部分，不宣称原子回滚。
- 将 Codex 的 `AGENTS.md` 作为源文档同步到目标安装根目录；Claude 目标文件名为 `CLAUDE.md`，Kimi 目标文件名为 `AGENTS.md`，使用原子替换避免半写入。
- 路径类型冲突、源缺失或目标位于源内部时停止，不猜测处理，也不删除冲突目标。
- 不同步任何 MCP 相关技能，也不同步凭据、会话、日志、MCP 配置、插件缓存或其他安装文件。

## 产出边界与交付

交付每个目标新增、更新和未变化数量、协作文档结果及路径适配状态；所有模式均保留目标独有技能；删除模式另报告删除清单、受保护残留及失败项，不因同步扩展用户指定范围。

## 验证与完成标准

核对预览与执行的源、目标、范围及参数一致；逐目标验证实际文件、引用可达性和路径归属。发现适配遗漏按流程修正，未完成不能声明同步成功。
