# 数据权限运行机制分析

## 分析目标

数据权限不是一组字段名，而是“身份进入系统后，如何获得功能、对哪些记录执行哪些动作、又如何把后续任务交给正确人员”的运行链路。必须分层确认，不能因发现其中一层便宣布权限完整。

## 必查权限层次

| 层次 | 要回答的问题 | 常见证据 |
|---|---|---|
| 身份与组织 | 当前人是谁，属于哪些组织、岗位、角色或租户 | 登录上下文、用户服务、组织关系、token/session claims |
| 功能权限 | 谁能看到菜单、路由或业务入口 | 菜单资源、角色资源关系、路由元数据、权限指令 |
| 操作权限 | 谁能调用新增、提交、指派、整改、复核、删除、导出等操作 | 后端鉴权注解、网关策略、方法校验、资源码、按钮权限 |
| 行级数据权限 | 同一接口返回哪些记录，按组织、本人、创建人、处理人还是任务关系过滤 | 数据权限拦截器、Mapper 条件、查询 DTO、数据范围 SQL |
| 字段/敏感权限 | 哪些字段不可见、脱敏或不可编辑 | 序列化、字段策略、前后端表单规则、脱敏逻辑 |
| 任务归属 | 当前待办为什么由此人处理，候选人怎样产生，转交后怎样生效 | 任务表、处理人字段、候选接口、指派逻辑、状态查询条件 |
| 组织/租户隔离 | 数据归属字段如何赋值，查询与写入是否都受隔离 | tenant/org 字段、自动填充、拦截器、唯一键、跨组织校验 |
| 审计与追责 | 谁在何时做了什么，是否保留原处理人和多轮记录 | created_by、updated_by、操作日志、历史任务、流水序号 |

## 运行链路

按实际代码依次追踪：

```text
登录身份/系统身份
  → 菜单与页面入口授权
  → 按钮或操作可见性
  → 服务端接口授权
  → 列表/详情行级数据过滤
  → 候选处理人范围
  → 提交时身份、组织和任务字段赋值
  → 状态推进与下一任务创建
  → 下一处理人的待办查询可见性
  → 历史、台账、导出和统计中的权限继承
```

每个箭头都应有代码、配置或表结构证据。缺少任一环节时，在文档中标明链路断点及影响。

## 权限矩阵

完整闭环分析至少包含以下矩阵：

| 角色/身份 | 入口/资源 | 允许操作 | 数据范围 | 判定位置 | 业务表约束 | 缺口 |
|---|---|---|---|---|---|---|

“管理员可操作全部数据”只有在角色判断和查询/更新范围都有证据时才能成立。仅看到页面按钮、角色常量、组织字段或候选人接口，都不足以证明完整授权。

## 人员选择与任务转交

对每次指派、领取、转派、打回或自动派发，逐项确认：

- 候选人从哪个接口、组织树、岗位、角色或配置产生；
- 前端是否只限制候选展示，后端是否重新校验被指派人合法性；
- 保存的是人员 ID、账号、姓名、部门 ID、组织编码还是多者组合；
- 人员和部门值来自当前登录人、前端请求、服务端回查还是外部同步；
- 下一任务记录何时创建，主记录是否冗余保存当前处理人；
- 列表如何只查到属于当前人的待办；
- 人员离职、跨组织、重复指派、任务打回和历史任务如何处理。

## 数据表设计与赋值核查

权限相关数据至少分为三类：

1. 平台授权数据：用户、角色、组织、资源及其关系。项目未持有这些表时，说明外部依赖与调用边界。
2. 业务归属数据：主记录的组织/租户/创建人/责任部门等字段，用于长期数据归属。
3. 流程任务数据：当前处理人、候选人、任务状态、轮次和处理结果，用于阶段性操作资格。

对关键权限字段建立赋值链：

```text
来源（登录上下文/请求/关联记录/外部系统）
  → DTO/参数
  → 服务端合法性校验
  → 实体赋值或自动填充
  → INSERT/UPDATE 字段
  → 查询过滤或鉴权消费
```

若字段由 ORM、MyBatis 插件、基类或数据库触发器自动赋值，必须定位真实机制；仅因实体继承审计基类不能断言数据库最终值。

## 常见断点

- 只隐藏前端按钮，没有服务端授权；
- 列表做了数据过滤，详情、导出、更新或删除可绕过；
- 提交人可任意传入组织或处理人，服务端不回查；
- 任务创建了处理人字段，但待办查询未按该字段限制；
- 主表组织字段与任务表处理部门不一致，状态推进后可见范围丢失；
- 外部同步绕过本地任务和权限字段赋值，导致台账可见但流程不可处理；
- 管理员、跨部门协同或上级监管通过硬编码角色/组织实现，缺少统一口径；
- 历史、导出、统计使用不同数据权限条件，形成侧漏或数字不一致；
- 只保存姓名不保存稳定 ID，或 ID/名称/部门由不同来源赋值；
- 删除、撤回、打回后没有回收待办或保留审计轨迹。

这些是检查方向，不是默认存在的问题。只有找到证据后才能写入风险结论。
