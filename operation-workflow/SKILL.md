# 运维操作

## 职责与边界

本技能维护执行顺序和授权节点。[工作空间](references/workspace.md) 定义初始化、清单和手册；[命令策略](references/command-policy.md) 定义通配规则与判定工具；[留痕](references/records.md) 定义方案、汇报、镜像和归档。环境事实保存在目标项目；通用底线读取 `~/ai-agent-config/config/force/collaboration-rule.md`。

## 输入与前置条件

确定项目目录、环境、服务器/服务、目标及成功标准。优先复用会话、清单和手册，只追问缺项。

## 执行流程

根据任务选择执行分支：

- 讨论、审查技能或方案：对话交付，不连接、不创建操作记录。
- 空项目、无服务器资料、目标未接入或必要入口/策略缺失：先按工作空间初始化；资料不足待补充，空模板不能冒充完成。
- 已有证据足够的本地文档维护：完成下方共用准备后更新受影响文件，进入汇报归档，不执行远端步骤。
- 只读排查/盘点：批准连接检查方案 → 采集 → 汇报归档。
- 服务器改动：连接检查 → 变更方案 → 批准执行 → 验证汇报 → 归档。

实际任务先读取目标策略、相关手册及留痕要求，检查 Git 基线并保存需求原文。初始化及生成/维护手册时读取工作空间要求；普通变更只补任务需要的事实。

1. **准备连接检查**：展示目标/环境、账号、渠道、主机密钥核验、凭据引用、检查命令和范围。连接与需确认的检查可合并申请；已有明确覆盖的授权直接复用。未获批准不连接。
2. **连接并检查**：核验主机、账号和环境；每个动作先匹配命令策略。只执行白名单或已获批动作，补充诊断只确认新增范围。只读任务完成后进入第 5 步。
3. **提交变更方案**：按留痕模板展示文件 diff/精确命令、顺序、影响、备份、失败停止条件、回退和验证；用户批准该版本后才能修改。一次批准覆盖所列命令、验证及条件回滚，不再逐条询问；方案变化只确认新增差异。
4. **执行与验证**：重查目标和文件/运行状态基线，漂移影响方案时暂停；先验证必要备份，再按获批顺序实施。记录命令、结果和证据，按成功标准检查业务。失败只做获批回滚并验证；结果未知先核实，不盲目重试。回读文件、更新镜像及受影响手册后再汇报。
5. **汇报并取得结果确认**：展示实际改动、验证结果、失败/未执行项，以及文档/镜像 diff、排除项和拟提交文件。等待用户确认结果及归档提交；只读任务明确无服务器变更。待确认不妨碍保存证据，也不触发自动回滚。
6. **归档提交**：核对获批内容没有漂移，按留痕门禁暂存精确范围；复用 `git-commit-message-authoring` 生成消息，再本地提交。push 另需明确授权。审批后出现新差异先补充确认，不覆盖获批快照。

## 核心约束

- 授权来自可信用户消息或审批系统，绑定目标、身份、范围和方案；换工具、重连或恢复会话不扩大权限。授权撤销/失效、身份不符、主机指纹变化时停止依赖动作。
- 凭据只用安全引用；主机密钥从可信来源核验，不关闭校验、不默认提权。只读也须限定敏感字段、输出量和资源开销。
- 命令通配免除逐条确认，服务器变更仍先批准整体方案；文件工具、上传下载、SQL/API 写入按相同副作用判定。禁止项不能被普通任务批准覆盖。
- 策略脚本只读配置和命令文本，不执行命令、不验证审批真伪、不提供系统级隔离；包装命令和脚本须展开审阅内层动作。

## 产出边界与交付

交付实际结果、记录路径、必要手册/镜像和 commit ID；分别说明服务器结果、人工确认、归档和 Git 状态。

新建或整体重构 Markdown 运维产物前读取 [固定产物模板](references/output-templates.md)，按实际交付块填充。原文保存和局部更新保留基线；既有授权、命令策略及归档门禁继续执行。

## 验证与完成标准

失败/取消保留证据，未完成审批或提交不称完整闭环；未做业务检查不称业务验收通过。

交付前核对需求、获批版本、实际动作、验证和提交内容对应。归档须通过 `python3 <技能目录>/scripts/check_archive.py index --repo <仓库根> --operations-root <仓库相对运维目录>`；它仅检查索引路径、类型和大小，不能替代敏感信息、授权或远端结果核实。

完整生成或整体重构运维产物后运行 `python3 <skills-root>/skill-authoring-standard/scripts/validate_document_template.py <产物路径> --template <本技能目录>/references/output-templates.md --block <实际产物块>`；格式检查不能代替授权、内容及实际运行结果核实。
