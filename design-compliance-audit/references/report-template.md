# 设计合规报告模板

本文件维护报告默认骨架和字段；审查范围、定级规则及完成标准由 [技能入口](../SKILL.md) 维护，具体检查项由 [合规清单](compliance-checklist.md) 维护。首次形成完整审核结论时读取；仅保存或局部更新保留原成果及证据状态。

生成前读取 [共用声明骨架](~/ai-agent-config/config/force/document-boundaries.md#共用声明骨架)，在下方结论与范围中填写具体职责、权威入口及检查时点。

按 [文档结构与输出规范](~/ai-agent-config/config/force/document-output.md) 使用**默认骨架**；组织遵循 [面向读者的组织与审阅](~/ai-agent-config/config/force/document-output.md#面向读者的组织与审阅)，以问题为审阅及复核单元。文档与实现的独立结论、范围、事实源、定级和类别保持；同根因跨类别时合并说明全部影响及各自判据，不以体验等级覆盖合规等级。

问题优先展示尚未解决的阻断项与必改项，再展示其它项；同组按 P0 → P3 排序，同级按任务或页面组织。已有编号保持稳定，不因排序重编号。开头结论列出阻断/必改问题编号及影响；已修复项带实际复核状态，未复核不能当作已关闭。无问题时不生成空索引。
