# 磁盘清理安全规则

仅当用户要求实际删除、清空、卸载或执行会回收空间的命令时读取本文件。普通磁盘分析不需要加载。

## 锁定目标

执行任何清理前，逐项解析并验证目标：

- 使用完整、明确的文件或目录路径，不依赖未解析的环境变量、通配符或命令替换。
- 说明内容类型、当前大小、预计可释放空间和风险等级。
- 排除系统目录、工作区根目录、用户主目录等范围过大的目标。
- 对聊天记录、同步盘、数据库、容器卷、密钥和工作资料标记高风险；无法判断时不执行。

## 取得确认

先向用户展示最终清单，再用一个直接、简短的问题确认是否按该清单执行。用户未明确同意前不得运行任何删除、清空、卸载、`rm`、`docker system prune`、`brew cleanup` 或同类命令。

如果用户调整范围、目标内容发生变化或实际命令会扩大影响，重新展示清单并再次确认。此前对分析或清理意图的认可不等于对新增目标的授权。

## 执行与复核

- 只处理确认清单中的目标，不顺带清理其它候选项。
- 优先使用移到废纸篓、应用自带清理或其它可恢复方式。
- 必须使用命令行删除时，先展示准确命令并再次确认；不得使用宽泛递归删除。
- 完成后重新采集相关磁盘快照，报告实际释放空间、未处理项，以及清理内容能否恢复。
