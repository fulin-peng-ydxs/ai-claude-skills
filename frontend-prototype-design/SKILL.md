# 页面原型设计

## 职责与边界

本技能制作评审用 HTML 或结构图原型，不承担生产实现或正式需求编写。本文维护形式选择、模拟交互、产物和验证契约；事实继承与保存由需求协作共用契约维护，视觉方法复用 frontend-design。

## 输入与前置条件

### 输入与职责

执行前读取 [需求协作共用契约](../requirement-doc-authoring/references/workflow-contract.md)，应用事实继承、确认和已有成果规则；本技能负责原型呈现与模拟交互，不要求先有正式 PRD，也不因共用契约而额外编写需求文档或技术方案。

- 读取用户指定需求、闭环、现有原型和相关页面，继承范围、角色、权限、状态和确认结论；已有需求编号就保留映射，没有则按页面功能点追溯，不另编 PRD 编号。
- 读取适用的 `AGENTS.md`、`DESIGN.md`、页面模板、真实共享组件和门禁；记录原型所依据的规范与实现状态。规范或基础迁移后，旧原型不能仅凭视觉近似继续作为合规开发依据；按授权用实际共享入口更新并验证，未完成时标明缺口并交回依赖它的计划。需要视觉或交互方案时配合 `frontend-design`，视觉原则不重复维护。
- 缺少影响业务成立的规则时处理相关阻塞；局部布局按依据自行决定，探索草案可用明确标注的假设。原型与需求冲突时说明差异，不静默改范围或业务规则。
- 仅要求原型不修改生产页面、不生成开发计划或重写需求；只做原型时报告已有需求/计划引用需更新的位置，由其他技能调用时交回实际路径、格式及验证状态。

### 原型形式选择

- 制作前先继承用户明确选择、调用方已取得的答复或本次可复用原型格式；都没有时，一次询问“生成 HTML 交互原型，还是结构图原型？”，简述差异并按评审目的推荐一种。不能把推荐当作答复，未答时可继续页面调研，暂不生成任一格式。
- HTML 可点击演示布局、联动和状态，适合需要观察交互或视觉效果的评审；结构图用页面线框与关系图表达区域、层级、跳转和操作说明，适合快速确认结构，不提供可点击交互。两种格式均须覆盖本次关键操作、状态和失败恢复。
- 普通模式开发计划涉及页面开发时必须进行上述选择，即使只是简单页面修改；已有答复或适用原型时不重复询问。用户明确不生成时尊重选择并向调用方返回替代依据与缺口；专业模式的原型前置或豁免由计划技能判断。独立使用及需求技能调用也沿用此处的格式选择，不默认强制 HTML。

## 执行流程

先继承输入与格式选择，按页面范围准备授权产物，再按共用内容实现所选格式，最后执行对应验证。格式未答时仅继续无关调研；仅保存已有结构图说明时保留基线，不重新制作原型。

布局重构或同类页面批量调整时，先在代表性页面验证受影响的状态，再推广：按相关性选择默认进入、辅助区展开、执行中需用户操作等状态，核对任务路径与区域边界。HTML 使用实际渲染与交互，结构图使用状态走读；不强制凑齐固定状态，不将此步骤变成已授权工作的额外批准门槛。

## 核心约束

### 共用内容与呈现

- 先确定入口、主要区域、操作顺序、数据展示、弹层和返回路径，按业务覆盖加载、空、错误、权限、成功及失败恢复；不机械添加无关状态。布局表达固定/滚动区域、长内容及目标终端的响应式或低高度退化。
- 对新增或重排区域说明其服务的任务、承载内容、出现条件、关闭或切换方式，以及操作后保留的上下文；常驻区域无需编造关闭行为。辅助区不能重复主区内容或替代核心任务入口，除非当前需求明确要求；在原型及既有交互说明中表达，不另建过程文档。
- 使用完成评审所需的最小结构，优先沿用项目风格、导航、布局密度和表格/表单/弹层模式；无依据时采用克制、可实现的低保真布局，不加入无关营销装饰或动效。
- 先区分目标产品内容与评审辅助内容。产品所需的字段帮助、校验、空态、状态及恢复提示按目标产品呈现；原型用途、能力限制、开发备注、验收说明和场景注入放业务界面之外的独立批注区，用明确边界及“非产品内容”等文字标识，不能仅给混入业务区的内容加“演示”前缀或换颜色。结构图用独立说明区或图例区分。
- 用于最终效果确认和开发交接的原型，关闭批注后的业务文案、控件与反馈必须能作为目标产品效果评审；不能让说明和演示工具替代真正的业务交互，也不能为清理批注删除应保留的产品帮助。探索或低保真稿须在评审说明中明确尚未定稿的部分，不将其宣称为最终效果。
- 首次生成或获准补全原型说明时读取 [共用声明骨架](~/ai-agent-config/config/force/document-boundaries.md#共用声明骨架)，在 HTML 独立批注区或结构图说明区交代评审用途、维护的布局/操作/状态范围，以及实际需求和设计规则的权威入口；业务区不承载这些说明。仅保存或局部更新保留授权基线。
- 辅助内容不增加线上功能，业务以已确认需求、页面功能点、验收和布局约束为准；无正式 PRD 时以当前有效输入为准。模拟结果不代表生产接口、权限或持久化能力已实现。
- 专项工作只呈现其页面影响：缺陷修复演示修复后的目标行为并保留相关未变交互；异步/第三方或批处理页面按需求区分受理、处理中、终态、部分失败及恢复入口，不用提交成功替代处理完成。纯后台迁移或内部重构没有页面影响时不虚构原型；无独立页面的技术验证可直接说明无页面产物。状态、恢复按钮和演示范围以有效输入为准，不为覆盖类型擅自新增业务能力。

#### HTML 交互原型

- 正式业务控件与需求一致：按钮、筛选、提交、弹层、切换、联动和状态变化必须有可用、可观察的模拟反馈，如校验、成功/失败、列表更新和返回；不能出现看似可用却无行为的控件。无法演示或未纳入的交互须禁用或显著标注，不与可用操作混淆。
- 评审状态切换、结果注入等辅助控件仅放独立批注区，文案含“原型演示”或同等标识，不进入产品导航、业务工具栏、筛选、表单、表格操作列、消息或主命令区；业务操作不能自动展开批注。多个页面共用评审入口与边界，禁止各页另造演示入口。
- 用于最终效果确认和开发交接的 HTML 原型必须支持完整隐藏批注、演示工具及其入口的产品预览，进入前说明恢复方式；切换保留草稿、筛选和当前业务状态，不额外提交或派发。评审区清楚披露样例数据、模拟能力和未接入范围；注入后业务区按目标产品展示结果，不夹带原型技术说明，也不以模拟反馈证明真实接入成功。

#### 结构图原型

- 每个页面有可辨识的区域线框，体现主次、核心字段/列、操作位置、固定与滚动关系；弹窗、抽屉及返回路径按相关性表达。导航图、业务流程图或区域名称列表不能独自替代页面线框；不要求像素尺寸和最终视觉样式。
- 用标识将图中区域/控件与操作说明对应，逐项写明触发、输入/校验、反馈、结果/状态、跳转/回流及失败恢复；共用规则集中说明，差异贴近条目。注明适用的权限、加载/空/错误状态、窄屏或低高度处理，不能把静态图称为交互已验证。
- 结构图说明按共用契约采用以下默认骨架，可合并简单项但不丢失适用信息；HTML 按页面布局与交互契约呈现，不强套 Markdown 章节：

```markdown
### 页面：名称
- 来源/功能点、入口与职责：
- 页面线框：使用 ASCII 等表达区域及核心控件的相对位置
- 跳转/联动关系：必要时补 Mermaid，并对应实际页面或区域标识

| 区域/控件标识 | 用户操作与输入/校验 | 系统反馈、结果及跳转/回流 | 权限、状态与失败恢复 |
| --- | --- | --- | --- |

- 滚动、长内容及响应式处理：
- 原型说明：本文用于页面评审与交接，维护本页布局、操作与状态说明；业务规则和设计契约沿用{实际需求/会话输入及 DESIGN 入口或当前归属}，模拟结果不代表生产实现。
- 假设与未决项：
```

## 产出边界与交付

### 页面范围与输出

- 用户指定的页面、保真度、格式和位置优先。HTML 使用可直接在浏览器打开的页面与模拟数据，不连接真实业务写入接口；确需服务或依赖时说明启动方法。结构图默认采用 Markdown 中的 ASCII 页面线框，跨页面导航、状态或联动关系复杂时补 Mermaid；用户指定其他图形格式时沿用。
- 新增页面制作对应原型；更新涉及主要区域新增、布局重排、跨组件联动、复杂表单/表格/图表、工作台、配置或可视化状态时，制作更新后页面或变更区域原型。未被用户或调用模式要求时，普通文案、字段、小按钮、简单显隐、局部校验和低风险提示无需自动制作；普通模式计划仍先询问选择，专业模式按其覆盖要求复用或补齐。
- 产物放本次功能目录的 `prototypes/`，已有需求文档或计划时复用其所属目录，无文档时按全局规则定位，不先生成 PRD。HTML 用 `{page-slug}.html`，结构图用 `{page-slug}.md`；跨页关系可集中表达并保留各页面单元。用户只要对话中的结构图时直接展示，不强制落盘。使用稳定业务命名，已有文件按共用契约维护，不另建平行版本；改格式时明确当前权威产物及需更新的引用。
- 先说明页面清单、路径、关键布局和未决项；沿用已有授权与确认，不重复批准。只查看或提方案不覆盖文件，只修改授权页面并保留有效布局与交互。

## 验证与完成标准

### 验证与交付

- 从业务使用者和接手开发者视角走读主链路及相关失败路径，检查结构、操作、状态、权限和数据口径，修复遗漏及误导控件。演示数据的数量、名称和排序只在承载业务规则或验收时核对，不扩展为模拟实现审查。
- HTML 须分别检查评审显示与产品预览：逐页及相关弹层确认辅助内容全部退出业务区，业务帮助与操作保留；触发业务操作、切换及恢复后检查无批注自动出现、无草稿丢失或重复动作。可稳定自动判断的边界接入既有检查入口并保留合法／违规样例，页面实际效果仍须浏览器确认。
- HTML 读取 [前端验证规范](~/ai-agent-config/config/force/frontend-verification.md)，实测本次相关场景，记录证据、结果和未验证项；检查相对链接、资源、批注隐藏及演示行为，不扩大为生产页面或全站验收。
- 结构图核对线框与操作/状态条目、区域标识、跳转目标及引用的一致性，走读主链路及失败恢复；检查 Markdown 线框排版，使用 Mermaid 时通过可用渲染器检查，无法渲染时标明未验证。无需启动业务页面做点击测试，不以结构审阅代替生产页面验收。
- 交付格式、文件链接或对话内原型、查看方式、验证范围与遗留问题；区分原型完成、用户确认和生产实现。HTML 浏览器验证受限或结构图渲染未验证时如实说明，不宣称通过，不额外建过程报告。
