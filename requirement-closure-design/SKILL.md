# 需求闭环设计

## 职责与边界

本技能补全需求在系统中如何跑通：功能链路、角色、状态、范围和未决事项；不承担正式需求编制或开发实施拆分。

本文维护闭环分析流程、确认处理和完成标准；[产物模板](references/closure-template.md) 唯一维护结构、字段及内容验收，成果继承、范围确认和阶段交接由下述共用契约维护。

## 输入与前置条件

输入为用户的粗需求、当前闭环成果及相关项目依据；先定位目标项目、当前讨论对象和已有确认状态。缺失事实先调研，影响闭环成立的业务选择按共用契约处理。

执行前读取 [需求协作共用契约](../requirement-doc-authoring/references/workflow-contract.md)，应用调研、继承、确认和阶段交接要求及其通用规范入口；无需读取正式需求技能全文。

## 执行流程

先识别操作与基线，继承已有成果和有效确认；按下表执行对应分支，不将完整分析作为保存、局部修改或阶段切换的前置。

首次分析或整体重构时，若核实仅属内部重构或技术验证且没有业务闭环变化，只说明适用范围及依据，不进入完整闭环产物分支，不虚构角色、页面或功能点。

| 用户意图 | 执行动作 |
| --- | --- |
| 首次分析、继续细化闭环 | 调研范围内的项目事实，按“核心约束”补全闭环，区分事实、推断和未决项；首次完整分析使用产物模板，继续细化维护当前基线。走读代表性场景后在对话中交付；没有保存请求时不建目录或文件。 |
| 明确确认闭环无问题、可落地，或要求保存 | 核对所指成果及后续有效修正，按共用契约保存为 `requirement-closure.md`；路径可确定就直接执行。不重新调研或补全，草案与未决状态如实保留；仅认可方向不视为完整闭环获批。 |
| 局部修改、重构 | 仅在获准范围调研、修改和核对受影响内容及引用；局部修改保留原结构，重构按授权调整。发现范围外缺口在交付中报告，不自动补全。 |
| 明确要求正式需求文档、PRD 或 requirement.md | 直接交接到 [requirement-doc-authoring](../requirement-doc-authoring/SKILL.md)，携带已有结论、依据和未决项，不先重跑闭环分析。 |

完成所选分支后，按对应的验证与交付要求结束本次工作，不自动推进下一阶段。

## 核心约束

完整闭环的内容与条件要求由 [固定模板](references/closure-template.md) 唯一维护；事实调研与确认处理遵循前述共用契约。

## 产出边界与交付

闭环阶段不分配正式需求编号，不自动生成 `requirement.md`、`prototypes/`、正式验收表或开发计划，也不提前展开性能、安全、兼容性专章。会影响业务成立的容量、安全或兼容边界仍须讨论，不能因不设专章而遗漏。

用户同时要求技术方案等复合成果时，首次输出分区承载，保存时完整保留；业务闭环部分只确定必要行为、边界和外部契约，类、函数、索引与内部事务编排留在技术方案部分，不升级为业务要求。

首次完整分析或获准重构时读取 [需求闭环产物模板](references/closure-template.md)；继续细化只读取受影响单元，保存按共用契约执行。

默认在对话中交付；满足上表保存条件时，按共用契约确定目录并保存为 `requirement-closure.md`，用户指定优先。产物包含闭环、范围、依据和未决项。首次生成或获准补全长期闭环文档时，在用途说明中明确：本成果维护业务闭环，正式编号与验收契约归需求文档，实施拆分归开发计划；仅保存、逐字保存或局部修改时保留授权基线，不为补边界扩写或重排；缺失说明在交付中报告。

## 验证与完成标准

- 分析或获准补全时，按一条代表性场景核对操作、反馈、结果、交接和失败恢复；局部修改只复核受影响链路，仅保存时对照原基线检查内容、引用和确认状态，不重新补全。不能靠章节齐全证明闭环。
- 核对功能范围索引能定位每个环节和独立功能点，角色操作、页面承载、状态交接与失败恢复同链可读；待决摘要能回到选择依据，阻塞与非阻塞不因合表而混淆。
- 范围不交叉，建议有状态，关键前提未知时不伪装成已闭环；生成成果按用户目标检查，保存成果按原基线检查。
- 保存后报告路径、新建或更新及遗留项，结束本次授权工作，不顺带生成正式需求、原型或计划。

首次完整分析或整体重构后运行 `python3 <skills-root>/skill-authoring-standard/scripts/validate_document_template.py <产物路径> --template <本技能目录>/references/closure-template.md`；字段内容按同一模板核对，保存和局部更新不借格式检查重排全文。
