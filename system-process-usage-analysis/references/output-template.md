````document-template
# 进程资源分析报告

## 1. 概览与证据范围

- 用途与归属：{{@本次只读排查的占用/嫌疑、证据和建议；非长期资产或监控，操作记录说明当前归属}}
- 范围、时点与资源压力：{{@系统及应用范围、采样起止/时区、间隔与次数、采集入口、进程数量及CPU/内存/IO压力；单次快照和不可测指标明确标注}}
- 当前结论与分类摘要：{{@证据支持的主要判断、分类统计和置信限制}}

## 2. 高占用与处理明细

- 排名与选择依据：{{@各资源维度排名及明细选择；无对象写条目情况及原因}}

### 对象：{{@应用与进程组名称}} <!-- repeat -->

- PID、父子关系与启动时间：{{@成员PID、父PID、启动时间、脱敏命令/应用身份及证据；跨次采样核对身份，不能只凭PID判定为同一进程}}
- CPU、内存、IO与线程占用：{{@指标名称、数值、单位与采集时点；CPU百分比的基准，内存的实际统计指标，IO为累计值、区间增量还是速率，以及线程数；不可测不填零}}
- 分类及聚合口径：{{@应用归类依据、纳入/排除成员及同一采样窗口内的汇总方法；单进程排名与进程组分开，不重复累计，不能直接求和的指标说明限制}}
- 主要嫌疑及持续性证据：{{@资源压力与对象的关联、业务/负载条件及时间序列或复采结果；区分瞬时峰值、持续占用和原因推断，单次快照不证明持续异常}}
- 处理建议、影响与授权条件：{{@建议动作及依据、受影响应用/任务与依赖、预期收益和需满足的授权条件；尚未执行写建议，目标身份复核及实际操作沿用技能入口}}
- 再次采样与判断方法：{{@可复现的采集入口、间隔/窗口、对象身份、同口径对照指标及改善/无改善的判据；获准操作后记录实际结果，未操作则给补测方法}}

## 3. 后续安排与盲区

- 处理顺序与依赖：{{@按低到高风险引用嫌疑项；Top进程与聚合值分别标注，不重复累计；诊断建议不授予实际操作权限}}
- 测量盲区与后续：{{@权限、指标、瞬时性或范围缺口及影响和补测入口}}
````

## 填写与内容验收

按应用进程组汇总宿主和子进程，资源维度保留Top导航，1至3个主要嫌疑须有依据；单次快照不能证明持续异常。无法获取的指标不填零。采样与实际操作结果分别表述，操作授权及身份复核沿用技能入口。
